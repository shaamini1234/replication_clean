3. Insolvencies (Gazette)

Two kinds of "death date" — they're different events, not duplicates:
  • Gazette insolvency date (this section) = economic death — when and why a firm entered a formal insolvency procedure (liquidation, administration, court order). The best death date for dynamism.
  • Companies House dissolution date (from the API extraction, in ch_company_profile) = legal death — when the firm was struck off the register, usually 1–3 years after the insolvency onset. Crucially, it's the only death signal for strike-offs — firms that closed without insolvency and never appear in the Gazette.
Rule of thumb: anchor on the Gazette onset where it exists; fall back to the CH dissolution date for strike-off firms.

4b. Gross Value Added (GVA) — computable coverage

GVA ≈ staff costs + operating profit + depreciation. All three are columns in the accounts, but all three are behind the "P&L wall", so GVA only exists where a firm filed full accounts.

Input parameterCoverage of all filings
staff costs~1%
operating profit~1%
depreciation~1–2%
all three present → GVA computable60,440 firm-years (0.15%)

So GVA is a large/medium-firm metric, not a population one — for economy-wide GVA use ONS ABS aGVA.

Computable-GVA firm-years, by size of firm

Skewed to medium & large firms — they're the ones that file a full P&L. Micro firms almost never appear.

Productivity by size — a deliberate non-result

GVA per employee in this covered subset is roughly £40–70k — the right UK ballpark. But we do not compare productivity across size bands from this data: which firms file a full P&L differs systematically by size, so any size ranking would reflect who chose to file, not real productivity. For productivity-by-size, use ONS ABS approximate-GVA — a properly grossed, representative sample. This subset is a selected large/medium-firm metric, useful for firm-level GVA levels, not for size comparisons.

5. The combined spine

Companies by how they join across sources

"No insolvency recorded" = trading or struck off (strike-offs aren't in the Gazette), so it is not the same as "still alive". Log scale.

Birth dates: sourced vs estimated

How the estimate works: UK company numbers are issued in sequence, so a number pins roughly when a firm was born. We learn the number→year mapping from the 5.7M live companies (which have both number and real date), then read off the year for dead firms with no surviving record. Validated on 2.5M held-out companies: correct to the year. Year-only, flagged birth_is_estimated=true, no source URL (it's derived, not looked up) — so it's easy to exclude from evidence-grade work.
